Arduino Chromebook Test

Checks whether this Chromebook can run the offline Arduino IDE. Nothing here uses the internet.

Steps

  1. Plug the Arduino Uno into the Chromebook with a USB cable.
  2. Wait for the automatic checks below to finish.
  3. Click Connect to Arduino and pick the Arduino from the list.
  4. Try the other buttons if you have time. The memory test can take up to 30 seconds.
  5. Click Copy results and send them to your teacher.
